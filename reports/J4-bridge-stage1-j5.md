# Донесення C5.1 → J5: J4 Bridge v0.1, Етап 1

**Предмет:** локальний автоматичний обмін синтетичними повідомленнями J3↔J5. **PR:** [#3](https://github.com/hellwikcoop-arch/easywar-staff/pull/3), база `setup/staff-bootstrap`. Точний коміт для приймання — HEAD PR після публікації цього донесення.

## Виконано

- Один початковий запис у SQLite-черзі запускає без ручного пересилання ланцюг `J5 → J3 → J5 → JE`. У JE потрапляє лише рішення рівня C зі станом `awaiting_je`; схвалення не генерується.
- Конверт фіксує ID задачі, ролі, commit SHA, тип, статус, час, раунд і спробу. Повторні ID/зміст, зайві раунди, третя спроба та перевищення викликів відхиляються.
- Ліміт Claude для J4 задано в центах: попередження $35, критичне $45, зупинка модельних доставок $50. Після перезапуску витрати й лічильники відтворюються з JSONL-журналу.
- SQLite-черга відновлює незавершений mock-виклик. Після збою до доставки повторює його; після запису в журнал завершує без повторної доставки й продовжує маршрут.
- Для того самого SHA перевіряється наявність доказу тестів, `C3 passed`, технічного приймання J3 та змістового приймання J5; за потреби — JE. PR автоматично не зливається.

## Докази локальної перевірки

- `python3 -m unittest discover -s tests -p 'test_j4_*.py' -v` — **17/17 пройшли**.
- `python3 -m j4_bridge` — `M-demo-1 delivered`, `M-demo-2 delivered`, `M-demo-3 awaiting_je`; одна mock-доставка J3, одна J5; модельована вартість Claude $0.12.
- `PYTHONPYCACHEPREFIX=/private/tmp/easywar-j4-pycache python3 -m compileall -q j4_bridge tests` — пройшло.
- `git diff --check` — пройшло.

Локально перевірено `codex-cli 0.163.0-alpha.11` і `codex login status` → `Logged in using ChatGPT`. JE підтвердив, що Claude API-ключ створено; прототип не читав його значення. Claude CLI локально не знайдено. Реальних Claude API, Codex inference і платних OpenAI API-викликів не виконували.

## Неперевірене та рішення

1. Контракт v0.4 називає роль `ADM`, а наказ — `J4 Bridge`; потрібне рішення JE про їхнє співвідношення перед живим запуском.
2. Живі адаптери Claude API/Codex CLI, фактичні модель і тариф, стартовий місячний баланс, захищене читання ключа, права GitHub та allowlist каталогів не перевірялись. Живий адаптер не реалізовано в Етапі 1.
3. Для живих викликів треба усунути невизначеність збою між зовнішньою доставкою й записом у журнал, захистити конкурентні запуски та перевіряти вартість до виклику. Поточне відновлення доведене тільки на `MockAdapter`.
4. Потрібні незалежна рецензія C3, технічне приймання J3 і змістове приймання J5 на одному коміті PR; рішення рівня C — JE. До інтеграційного тесту J4 не готовий до автономної роботи.
