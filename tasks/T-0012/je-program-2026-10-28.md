5. Запустити дозволену повну регресію в межах бюджету.
6. Передати diff і SHA C3.
7. Самостійно усунути обов'язкові зауваження.

9. Записати технічне приймання J3.
10. Передати J5 готовий пакет для змістового приймання.

8. Відновлення роботи
Після кожного значущого рубежу зберігай checkpoint у дозволеному робочому просторі:

* поточне завдання та етап;
* останній контрольний SHA;
* виконані перевірки;
* витрати;
* дозволені наступні дії;
* блокування й потрібні рішення.

Якщо Claude Code завершує сесію, checkpoint має дозволяти новій сесії продовжити без повторного дослідження й без скидання лімітів.
Не стверджуй, що виконання триває у фоні, якщо процес Claude Code фактично зупинився.
