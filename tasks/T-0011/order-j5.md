**Статус: ПРОЄКТ-ВОРОТА — не зареєстровано** (немає `task_created`). Ліміт **180** stub/fake-викликів затверджено JE (JE-T10-01 п. 1; JE-T10-02 п. 4). **Реалізацію не починати до окремого рішення JE** (JE-T10-02 п. 6): наказ змінює модель довіри й, можливо, контракт.
**Ініціатор:** J5 · **Виконавець:** J3 · **Координатор:** ADM / J4 · **Режим:** synthetic-only, stub, без платних API
**Залежність:** виконується **після T-0010** (спільні файли `close.mjs`, `store.mjs`; JE-T10-01 п. 3). **База:** вершина прийнятого T-0010 — визначає JE.

## 1. Мета

`j4 close` (і `run --once`) відмовляють, коли `J4_HOME`, `J4_LEDGER` і події J4 в `events.jsonl` не належать одній установці J4 (усунення F-T9-18).

## 3. Завдання J3 (після воріт)

1. marker установки в сховищі й першою подією журналу;
2. перевірка збігу marker-а сховища, журналу й закріпленого значення;
3. звірка подій J4 в `events.jsonl` (`ref: j4-ledger#seq=N`, `ledger_hash`) із записом seq N наданого журналу;
4. звірка ескалацій за трьома джерелами (сховище, журнал J4, журнал завдання);
5. негативні CLI-тести: хибна, порожня, чужа пара, обрізаний/підмінений журнал, чужий marker; мутації кожної перевірки;
6. після приймання — `tasks/T-0009/runbook-close.md` скоротити або зняти; `tasks/T-0009/tools/reconcile-close.mjs` перенести в `bridge/` або залишити з поясненням.

**Межі:** `bridge/src/store.mjs`, `close.mjs`, `router.mjs` (поле в подіях), `bridge/bin/j4.mjs`, тести, `DESIGN`, `README`; `CONTRACT_v0_4.md` і `bridge/config/**` — лише в межах рішень G2/G3.
**Не входить:** `bridge/src/acceptance.mjs`; автентифікація `by`; планувальник; live; реальний `j4 close`.

## 4. Критерії приймання

хибна/порожня/чужа пара → відмова з окремим кодом; правильна пара → поведінка без змін; вікно до першої синхронізації описане чесно (звірка з подіями J4 неможлива, коли їх ще немає, — закривається marker-ом); усі мутації знайдено; наявні тести проходять; C3 за diff; технічне J3, змістове J5, **остаточне JE (`key_decision: true`)**; `j4 close` для реального завершення лишається забороненим, доки JE не вирішить окремо; `done` не встановлювати.
