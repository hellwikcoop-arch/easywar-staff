## 3. Що робить оновлення з доказами

Правило «той самий SHA» означає, що докази для `9ea0994` автоматично на новий SHA не переходять. Водночас
дерево `collective/`, ADR, вектори й чекліст після злиття побайтно ті самі, змінюється лише оточення крейту
(новий модуль `dashboard_layout`, міграція 0018). Тому повторювати повний огляд не потрібно, достатньо вузько
довести тотожність і повторити те, що залежить від збірки.

| Доказ на 9ea0994 | Після злиття |
|---|---|
| CI Linux | повторюється автоматично на новому SHA |
| C3 №2 (c2d8d4f) і №3 (9ea0994) | вузька перевірка C3 лише коміту злиття (див. крок 4) |
| G06 macOS (Codex) | повтор `cargo test --locked collective::` на новому SHA або рішення JE про рівноцінність |
| G06 Windows | ще не зроблено, робити одразу на новому SHA |
| J3 technical, J5 content | ще не зроблено, робити на новому SHA |
