# F-15 — відстежуване зауваження (відкрите)

**Статус:** tracked, **не виправлено**. Перенесення на C3b/C5 погоджено J5 22.10.2026.
Закривається лише тестами й перевіреним кодом на конкретному коміті з рецензією C3.
**Джерело:** рецензія C3 C1b, `reports/T-0002/010.yaml`; код `src/shared-table-core.js`, `applyOperation`,
EasyWAR `main` після злиття PR #157 (контрольний коміт `9ec729ee2dae539ab70be028756644785201348a`).

## Опис

Після виправлення F-8 порядок перевірок такий: форма → таблиця → схема → значення → підпис →
**право запису** → дубль/цілісність за `op_id`. Тому повторна доставка операції, яку вже прийнято,
від автора, якого згодом виключили з `writers` (відкликання чи зміна призначення), дає `rejected /
no-write-right`, а не `duplicate`. Стан при цьому не змінюється.

Друга частина: межовий тест `tests/collective-core-boundaries.test.mjs` не перевіряє, що всі
файли з `C1_PLANNED_CORES` справді існують; ядро з іншою назвою пройде повз перевірку.

## Умови відтворення (синтетика)

1. `s1 = applyOperation(empty, opA, { writers: [A, B], verify })` → `applied`.
2. `applyOperation(s1, opA, { writers: [B], verify })` → `rejected`, `no-write-right` (очікувано для
   C3b — `duplicate` або окремий статус «вже застосовано»).

## Ризик

Низький для C1 (стан не змінюється, ядро не підключене). Для C3b/C5: повторна синхронізація після
відкликання може показувати людині хибні «відмови» на вже прийняті операції, а лічильники
доставки — розходитися з журналом. Межовий тест: нове ядро з неочікуваною назвою не буде перевірене.

## Цільовий етап

C3b (Rust-сховище й політика) — семантика повторів; C5 — показ людині. Межовий тест — при
злитті останнього підетапу C1 (C1d) або в C3b.

## Критерій приймання

- Тест: операція, прийнята від автора з правом запису, при повторній доставці після втрати права
  дає погоджений результат (`duplicate` або окремий статус), стан не змінюється, нова операція
  того самого автора без права — `no-write-right`.
- Тест: усі файли `C1_PLANNED_CORES` існують після завершення C1 (або перелік скорочено рішенням).
- Рецензія C3 `passed` на коміті з виправленням; запис цього файлу оновлено з `closed_by`.
