# JE → J3 — автономне виконання EasyWAR

**Режим: EXECUTE UNTIL COMPLETE OR BLOCKED**

Мета: усунути необхідність мого ручного втручання після кожного кроку. Не вимагай підтвердження JE для звичайних технічних рішень, уже дозволених наказом.

## 1. Основне правило

Отримавши затверджене завдання:

- Самостійно плануй послідовність реалізації.
- Виконуй код, тести, виправлення та перевірки без проміжних запитів до JE.
- Якщо тест не пройшов — аналізуй причину та виправляй у межах дозволених спроб і бюджету.
- Передавай код на незалежну рецензію C3.
- Виправляй зауваження C3 у межах погодженого scope.
- Повторюй дозволений цикл до виконання критеріїв приймання або появи стоп-умови.
- Передавай J5 готовий результат для змістового приймання.

Не зупиняйся лише через те, що завершив один підетап. Продовжуй наступний дозволений крок.

- Не змінювати гілку PR №6.

## 3. Коли звертатися до JE

Тільки якщо виникає:

- необхідність змінити контракт, модель довіри, безпекові повноваження або scope;
- потреба в платному API чи live-режимі;
- ризик перевищення бюджету або ліміту спроб;
- блокувальне зауваження, яке неможливо виправити в межах наказу;
- потреба в злитті PR, активації планувальника або іншій забороненій дії.

У таких випадках зупини лише заблоковану роботу, збережи результати й подай JE один конкретний запит із варіантами рішення.

## 4. Звітність

Не надсилай проміжних повідомлень із проханням «продовжувати».

Веди журнал фактичних результатів, витрат і SHA. Після завершення подай один підсумковий звіт:

- що реалізовано;
- які тести пройдено;
- висновок C3;
- контрольний SHA та PR;
- фактичні витрати;
- що залишилося;
- які рішення потрібні JE.

## 5. Заборони

Не обходити захисти, не підміняти приймання J5/C3/JE, не зливати PR, не використовувати реальні оперативні дані, не запускати платні API або live без окремого дозволу.

Якщо сеанс чи ліміт середовища перервав виконання — зберегти відновлюваний стан і не стверджувати, що робота триває у фоні без працюючого виконавця.

**Принцип:** працювати автономно настільки, наскільки дозволяє затверджений наказ, і звертатися до JE лише на справжніх контрольних воротах.
